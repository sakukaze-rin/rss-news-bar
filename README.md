# RSS NewsBar

>⚠️这是一个完全由AI agent制作的项目，并且仍在持续更新中，因此可能会存在各种问题。另外由于作者缺乏代码能力，因此可能无法及时对社区的问题反馈做出响应，还请谅解。此外由于我没有苹果开发者账号所以该应用目前没有签名，需要手动授权安装。

一个运行在 macOS 菜单栏的 RSS 标题滚动 demo，默认使用 `https://rss.cnbeta.com.tw/`。

## 运行

需要 macOS 13+ 和 Swift 6：

```sh
swift run RSSNewsBar
```

或者生成可双击运行的应用：

```sh
chmod +x scripts/build-app.sh
./scripts/build-app.sh
open "dist/RSS NewsBar_0.2.1 beta.app"
```

生成可分享的测试 DMG：

```sh
./scripts/build-dmg.sh
```

输出位于 `dist/RSS-NewsBar-v0.2.1-beta.dmg`。安装包默认生成 Apple Silicon 与 Intel 通用应用；当前为 ad-hoc 签名的内部测试包，未使用 Apple Developer ID 公证。

左键点击滚动标题会用系统默认浏览器打开原文；右键点击滚动栏可以打开菜单。鼠标悬停时可使用滚轮回看或跳过新闻。

右键菜单中的“管理 RSS…”可以：

- 添加、删除、启用/停用、拖动排序 RSS 源
- 为每个源设置刷新频率和 1/3/7 天时间范围
- 调节滚动速度、随机播放、悬停缓动暂停
- 自定义滚动栏宽度、字号和颜色
- 手动清理标题缓存
- 暂时最小化为单一菜单栏图标

RSS 源列表会显示每个源最近一次刷新状态和获取条数，并支持多选后删除。

## 设计说明

当前 demo 只解析 RSS/Atom 的标题、链接和发布时间，不读取正文。每条标题前显示来源名称，新增标题首次滚动时显示 `🆕`。后续可将 favicon 下载缓存接入 `RSSFeedService`。

## Demo 边界

- 已实现：菜单栏常驻、连续滚动、悬停缓动暂停、速度调节、跨源均衡随机播放、新标题标记、刷新周期、时间范围、标题缓存、字号/颜色、宽度调节和可关闭的两端渐隐。
- 下一步：favicon 自动获取与缓存、自动清理策略、登录启动、签名与公证。
- macOS 没有公开接口精确读取其他菜单栏图标占用宽度；自动紧凑模式已暂时移除。
